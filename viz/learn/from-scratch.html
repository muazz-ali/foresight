Inside attention, from scratch

A tiny made-up example that uses the same steps as the action expert. Two numbers per token, so you can watch the arithmetic. The real expert uses a much longer list, and the same moves.

Toy numbers, real order of steps. Even layers look backward (self-attention). Odd layers read the frozen memory (cross-attention). Ten small steps walk noise toward a hand path. This page is not an Archify diagram: Archify can light up boxes, and this lesson can play, pause, and reset the numbers.
